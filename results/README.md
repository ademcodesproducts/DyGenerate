# results/

What this folder is for: everything derived from the responses, which can always be rebuilt by rerunning score.py and analyze.py.

What goes here:

- scores.csv from score.py, one row per sample.
- The tables from analyze.py: accuracy per cell, home advantage, difference in differences with intervals, ranking flips, truncation rates.
- The plots: accuracy against difficulty per task, home and away side by side.
- The short written summary of Exp 1, which is the input to the Gate A decision on Nov 23.
